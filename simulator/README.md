# System Design Lab

Интерактивный симулятор к главам 1–6. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Как открыть
- **Локально:** открой `simulator/index.html` в браузере.
- **Онлайн:** в настройках репозитория включи GitHub Pages (Settings → Pages → ветка → папка `/`), страница будет по адресу `…/simulator/`.
- Конкретная глава: `index.html#ch4` (ch1…ch6).

## Как пользоваться
1. Слева крутишь **нагрузку** (пользователи, поток сообщений и т. д.).
2. Добавляешь и убираешь **блоки архитектуры**. Рядом с кнопкой видно, что изменится (выдерживаемая нагрузка, задержка, цена, сложность, качество).
3. В центре **путь запроса**: загрузка каждого узла, узкое место подсвечено.
4. Справа итог, цели главы, подсказки и раздел **«Что нужно понимать»**: что за блок, какую проблему решает, что надо знать перед добавлением и чем придётся заплатить.
5. **Автомасштаб** подбирает число серверов под ≈70% загрузки, поэтому архитектуры удобно сравнивать по цене и сложности. Выключи его, чтобы крутить число серверов вручную.

## Устройство
- `engine.js` — движок: считает загрузку узлов, задержку, доступность, цену, сложность, качество.
- `scenarios/chN.js` — описание главы: входные параметры, узлы, блоки (с текстом «что понимать») и правила-подсказки.
- `app.js`, `style.css`, `index.html` — интерфейс.
- `test.js` — быстрая проверка моделей: `node simulator/test.js`.

## Важно
Это **учебная модель**: числа правдоподобные, но не измерения. Её задача показать направление эффекта и компромиссы, а не точные значения. Сверяйся с книгой и конспектами.

## Как добавить главу
Скопируй любой `scenarios/chN.js`, подключи в `index.html` и задай `stages`, `components`, `rules`, `goals`.
